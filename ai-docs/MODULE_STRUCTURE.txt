Module Enable Pattern
======================

In hosts/<hostname>/configuration.nix:

imports = [
  ./hardware-configuration.nix
  ../../modules  # Import all module categories
];

# Enable specific modules
modules.desktop.niri.enable = true;
modules.desktop.waybar.enable = true;
modules.desktop.mako.enable = true;
modules.desktop.rofi.enable = true;

modules.development.claude-code.enable = true;
modules.development.codex.enable = true;

modules.terminal.kitty.enable = true;
modules.terminal.fish.enable = true;
modules.terminal.starship.enable = true;

modules.utilities.cli-tools.enable = true;

modules.communication.vesktop.enable = true;
modules.communication.zoom.enable = true;


Module File Pattern
====================

Each module follows this structure:

{
  config,
  lib,
  pkgs,
  ...
}:
with lib; let
  cfg = config.modules.CATEGORY.MODULE;
in {
  options.modules.CATEGORY.MODULE = {
    enable = mkEnableOption "Description of module";
  };

  config = mkIf cfg.enable {
    environment.systemPackages = with pkgs; [
      package-name
    ];
    # Additional configuration...
  };
}


Available Packages
==================

Through specialArgs, modules have access to:
- pkgs              # Default nixpkgs (nixos-unstable)
- pkgs-stable       # Stable channel (nixos-25.05)
- pkgs-edge         # Edge channel (nixpkgs master)
- pkgs-unstable     # Alternative unstable source
- inputs            # All flake inputs
- outputs           # Flake outputs


Building and Testing
=====================

From /home/titan/.flakes/titan-os/:

# Check syntax and evaluation
nix flake check

# Build without activating
sudo nixos-rebuild build --flake .#launchpad

# Test (temporary until reboot)
sudo nixos-rebuild test --flake .#launchpad

# Apply permanently
sudo nixos-rebuild switch --flake .#launchpad

# Update all channels
nix flake update


Module Summary
==============

Desktop (4 modules):
  - niri      : Wayland compositor with scrollable tiling
  - waybar    : Status bar for Wayland
  - mako      : Notification daemon
  - rofi      : Application launcher

Development (2 modules):
  - claude-code : AI-powered code editor
  - codex       : Development tool

Terminal (3 modules):
  - kitty     : GPU-accelerated terminal emulator
  - fish      : User-friendly shell with smart features
  - starship  : Cross-shell prompt customization

Utilities (1 module):
  - cli-tools : Bundle of essential CLI tools
                (bat, fzf, ripgrep, curl, jq, yq, zoxide, fd, eza)

Communication (2 modules):
  - vesktop   : Discord client with Vencord
  - zoom      : Video conferencing

Total: 12 modules across 5 categories
